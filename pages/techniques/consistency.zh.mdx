## 什么是自洽性？

自洽性（Self-Consistency）是一种提示技术，它让 AI 多次尝试同一个问题，然后选择最一致的答案。

## 工作原理

```
1. 让 AI 多次回答同一个问题
2. 收集多个答案
3. 分析答案的一致性
4. 选择多数一致的答案
```

## 为什么要使用？

1. **减少错误** - 多次验证提高准确性
2. **避免偏见** - 单次回答可能受偏见影响
3. **复杂问题** - 对需要推理的问题特别有效
4. **提高可靠性** - 通过一致性检验

## 如何使用

### 基础框架

```
请用多种方法解答以下问题，选择最一致的答案：

问题：[你的问题]

要求：
1. 用至少 3 种不同方法解答
2. 分析各方法的结果
3. 如果结果一致，选择该答案
4. 如果不一致，解释原因
```

### 示例

```
问题：如果小明有10个苹果，给了小红3个，又买了5个，现在有多少个？

方法1：10-3+5=12
方法2：10+5=15，15-3=12
方法3：先算总和10+5=15，再减去给出的3，15-3=12

结果：三种方法都得到12，答案一致为12
```

## 应用场景

| 场景 | 示例 |
|------|------|
| 数学计算 | 多次计算验证结果 |
| 逻辑推理 | 多路径推理验证 |
| 代码生成 | 多种实现比较 |
| 决策建议 | 多角度分析 |

## 进阶技巧

### 1. 指定推理方法

```
请用以下方法分别解答：
1. 直接推理
2. 反证法
3. 归纳法
```

### 2. 权衡选择

```
如果多个答案不一致：
- 记录每个答案的支持度
- 分析最合理的解释
- 或者返回"无法确定"
```

### 3. 成本控制

```
对于简单问题，不需要多次验证。
只在复杂问题时使用自洽性。
```

## 与其他技术结合

- **CoT + 自洽性**：先思维链再多次采样
- **Few-shot + 自洽性**：多个示例验证
- **Self-reflection + 自洽性**：检查后再次验证

## 注意事项

- 增加 API 调用成本
- 不是所有问题都需要
- 简单问题不需要自洽性
